Beschrijving

Binnen het scenario ‘Evaluatie leerproces’ van de praktijksituatie ‘Evalueren leervoortgang en resultaten’ is de behoefte beschreven om de resultaten (cijferlijst) van een leerling op te kunnen vragen bij de referentiecomponent Administratiesysteem Leerresultaten. Hiervoor is een aanvullende gegevensdienst nodig.

Het ligt voor de hand om deze gegevensdienst uit te werken binnen de werkgroep ‘Toetsen en examineren’, omdat daar al de Results API is gedefinieerd voor de uitwisseling van toetsresultaten.

De voorgestelde Grades API (werktitel) vormt een aanvulling op de Results API en onderscheidt zich op een aantal punten:

  • Transactiepatroon: de Results API werkt volgens melding – bevestiging (push vanuit het Toetssysteem), terwijl de Grades API een bevraging mogelijk maakt waarbij de afnemer resultaten opvraagt bij het Administratiesysteem Leerresultaten.

  • Status van het resultaat: de Results API levert het resultaat zoals dit vanuit het Toetssysteem wordt aangeleverd. Bij de Grades API gaat het om resultaten die in het Administratiesysteem Leerresultaten een vastgestelde status hebben gekregen en daarmee een meer formeel karakter kunnen hebben. Dit sluit aan bij het begrip ‘onderwijsresultaat’ zoals dat binnen ROSA wordt gehanteerd.

  • Resultaten en scores: via de Grades API worden in principe alleen de geregistreerde resultaten uitgewisseld en niet de onderliggende scores waarop deze resultaten eventueel zijn gebaseerd.

  • Weging: naast het resultaat kan ook de weging worden uitgewisseld, bijvoorbeeld om aan te geven of en hoe zwaar een resultaat meetelt bij het bepalen van een gemiddeld resultaat.

  • Resultaattypen: voor de mogelijke typen resultaten kan gebruik worden gemaakt van dezelfde gedeelde definitie als binnen de Results API.

  • Ontkoppeling van toetsapplicaties: de afnemer hoeft niet met afzonderlijke toetsapplicaties te koppelen, maar alleen met het Administratiesysteem Leerresultaten.

  • Aanvullende resultaten: de Grades API kan ook resultaten bevatten die rechtstreeks in het Administratiesysteem Leerresultaten zijn ingevoerd, bijvoorbeeld resultaten van papieren toetsen.

Onderbouwing van nut of noodzaak

De bestaande Results API is gericht op het aanleveren van afzonderlijke toetsresultaten en onderliggende scores vanuit een Toetssysteem en biedt geen mogelijkheid om een actueel, samengesteld overzicht van vastgestelde resultaten op te vragen. Een aanvullende gegevensdienst maakt het mogelijk om deze resultaten (onderwijsresultaten), eventueel inclusief hun weging, vanuit één centrale bron – het Administratiesysteem Leerresultaten – op te halen, zonder koppelingen met afzonderlijke toetsapplicaties.
